# Assignment Mapping

The supplied assignment requires a resume-driven, role-specific RAG interview system with React/Next.js frontend, Python FastAPI/Flask backend, database persistence, modular services, embeddings, vector database, retrieval, grounded question generation, session continuity, and a final structured summary.

This starter implements those components. The provided book should be used as the primary knowledge source; its PDF should be supplied locally to `backend/data/knowledge_base/` and ingested with `python scripts/ingest_knowledge.py`. The book PDF is excluded from Git.
